Ícone de Recompensas

O ícone atual é o redeem do Material Symbols: uma caixa com laço que, no tamanho pequeno do menu, parece uma tesoura em cima de uma caixa. Abaixo, alternativas do mesmo conjunto (Material Symbols Rounded), cada uma no menu ☰ com Recompensas selecionado e no quadro grande da loja vazia. Toque para marcar a preferida.

Onde o ícone aparece

  • Menu ☰, item Recompensas (ShellModels.kt).
  • Loja vazia (RewardsContent.kt).
  • Ícone “Presente” que você pode escolher para uma recompensa (AppIcon.GIFT): trocar o desenho mantém a chave salva, então suas recompensas continuam com o mesmo ícone, só que redesenhado.
