# Contrato de interface e portabilidade

- Exportar backup → opções de proteção → criar documento → gravar → resultado.
- Importar backup → abrir documento → solicitar senha se protegido → validar → mostrar data e listas/tarefas/hábitos.
- Destino novo → Importar. Destino pessoal → Cancelar, Exportar backup, Substituir e importar.
- Interpretar conteúdo independente do nome, extensão, provedor ou ID Android. Prévia e confirmação usam a mesma cópia.
- Inserir os registros sob uma transação com valores vinculados. Não aceitar instruções executáveis do arquivo.
- Interrupção exige recuperação consistente e repetição deve preservar os mesmos registros.
