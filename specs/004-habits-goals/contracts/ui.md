# UI contract

- Hábitos: real active/paused habits, New/Edit, type/goal, progress and accessible actions.
- Inbox/list Hábitos tab reuses shared list membership. Hoje/review filters remain Tudo/Tarefas/Hábitos.
- Practice: record today/yesterday/date; daily scheduled dates independent; attained flexible goals
  under collapsible Metas cumpridas. Avoid/limit always visible and multiple events supported.
- Detail: calendar of records, period progress, current/best/pending streak; correct/delete record.
- Review: forgotten-date entry plus confirm failure or event completeness. Corrections changing
  reviewed result reopen it. Counters aggregate real tasks/habits once.
- Edit: current target recalculation preview or next-period effect; changed type/unit always future.
- Pause/resume/exclude/restore: explicit partial target control; deletion confirmation preserves history.
- History: Hábitos excluídos includes consultation and restore; missing list requires destination choice.
- Errors stay visible with retry and preserved input; no false save confirmation.
- Portuguese resources, scroll, 48dp actions, light/dark/system and large fonts.

Habit history is reached through habit detail; the Hábitos screen includes Hábitos excluídos.
The approved Histórico de moedas drawer item retains its honest unavailable financial state.
