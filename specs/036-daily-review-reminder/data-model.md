# Dados

A linha existente reminder_settings conserva summaryMinute e lastSummaryDate. O primeiro é o minuto local opcional.
O segundo registra a última data de revisão processada (entrega ou silêncio). Valores escritos por versões anteriores
continuam válidos. A reserva da data confere também o horário configurado. Nenhuma tabela ou permissão nova é necessária.
Tarefas, períodos e registros de prática fornecem entradas de leitura para a decisão.
