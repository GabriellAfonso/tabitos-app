# Quickstart validation
From project root with installed JDK/Android SDK:
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease
Run connectedDebugAndroidTest separately when an emulator is available.

1. Upgrade a schema2 database with tasks/habits/history: wallet0/XP0/level1; source data unchanged.
2. Complete easy task: +5/+10; undo, edit tables, redo: original pricing and one active award.
3. Confirm high-importance failure near−300; inspect clipping and refund effective deduction only.
4. Practice three days/week: day rewards, same-day dedupe, cap after target, correction reopens capacity.
5. Limit one/week with three events: two penalties; correct first event, inspect deterministic reassignment.
6. Confirm within-limit closed period once; correction invalidates reward until completeness re-confirmed.
7. Set coin/XP/penalty0 and10000; reject negatives/fractions/out-of-range without modifying committed prices.
8. Inspect immutable history after source deletion; relaunch offline; no sample transactions/manual grants.
9. Validate threshold100/250/450/252450, multiple-level gains and downward correction.
10. Exercise light/dark/system, landscape, enlarged fonts and accessibility labels; record coverage limits.
