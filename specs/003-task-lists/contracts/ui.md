# UI contract

- Drawer: Inbox, real colored/icon lists, create/manage lists; standard destinations remain.
- Tarefas: selected Inbox/list, Tarefas/Hábitos tabs, capture; pending move-up/down controls and
  collapsible resolved content. List manager edits name/color/icon/order and confirms deletion.
- Hoje: existing balance/level and notice; Tudo/Tarefas/Hábitos; day section then weekly section.
- Revisar pendências: real expired OPEN entries and matching total badge/notice, same filters.
- Calendário: date selector and tasks for that date; no expanded calendar redesign.
- Editor: optional fields, friendly selections for recurrence/endings, date/time validation,
  checklist labels, difficulty/importance manual precedence. Save pending disables duplicate actions.
- Detail: checklist checks, actual completion date, confirm unchecked count, Não será feita,
  undo outcome, delete/edit scopes; overdue reschedule requires explicit missed-deadline review.
- Durable error is shown until dismissed/retried; draft/confirmation stays on failure. No false success.
- Visible strings in Portuguese resources; touch targets at least48dp and scrolling with large fonts.
- Production contains no samples; previews provide explicit data.
