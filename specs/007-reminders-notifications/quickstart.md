# Validation guide

1. Run Gradle :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease
   :app:assembleDebugAndroidTest with --console=plain --max-workers=2; connectedDebugAndroidTest when available.
2. Create fictitious task/checklist/habit. Save two reminders, edit/remove, restart; verify unchanged deadlines.
   Exercise current/future series scope, relative explicit reference and weekly no-fixed-day schedule.
3. Contextual permission/exact access; observe actual timed notification. Concluir opens checklist and financial
   confirmations; habit only Abrir/Adiar. Verify warm/cold navigation and Back.
4. Snooze10/30/60/custom; repeat without duplicates, reject past; resolve/pause before firing cancels.
5. Summary initially off; chosen time/counts match Hoje/review, empty day, change/disable persists.
6. Deny permission/block channel then restore: one relevant recovery summary, no burst or false delivery.
   Repeat recovery three times, delete source, reach practice target; avoid/limit remain eligible.
7. Reboot/update/timezone/date changes reconcile without domain/accounting changes.
8. Light/dark/system, font200%, landscape, lock-screen generic content and available TalkBack.
9. Record actual evidence and unavailable API24/physical/device restrictions in verification.md.
